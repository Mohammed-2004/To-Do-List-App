# 📝 To Do List App

A simple and interactive **To-Do List application** built using **HTML, CSS, and Vanilla JavaScript**.  
The project allows users to add, manage, prioritize, and remove tasks بسهولة ومن غير أي مكتبات خارجية.

---

## ✨ Features

- ➕ Add new tasks
- 🗑️ Delete tasks
- ⭐ Mark tasks as important (starred tasks move to the top)
- ❤️ Toggle task reaction (salute / heart)
- ✔️ Interactive UI with smooth hover effects
- ⌨️ Form validation (prevents empty tasks)

---

## 🛠️ Technologies Used

- **HTML5** – Structure
- **CSS3** – Styling & animations
- **JavaScript (Vanilla)** – Logic & DOM manipulation
